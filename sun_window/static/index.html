ใส่พิกัดกับทิศของหน้าต่าง แล้วดูว่าแดดเข้าช่วงไหนของวันและของปี และทิศไหนโดนแดดมากที่สุดหรือน้อยที่สุด

รายละเอียดรายวัน

เส้นทางดวงอาทิตย์ในวันนั้น

แดดตกกระทบหน้าต่างตลอดปี (แกนนอน = วัน, แกนตั้ง = เวลา)

เลื่อนเมาส์หรือแตะบนกราฟเพื่อดูค่า
สีส้มเข้ม = แดดตกฉากกับผนังมาก, สีฟ้าเทา = กลางวันแต่ไม่มีแดดเข้า, สีเข้มสุด = กลางคืน

ช่วงที่มีแดด และช่วงที่ไม่มีแดด (ทิศที่เลือก)

ชั่วโมงแดดเข้าเฉลี่ยต่อวัน แยกรายเดือน

ฤดูกาลกับแดดที่เข้าห้อง

ภาระความร้อน = แดดหน้าร้อน + ครึ่งหนึ่งของแดดหน้าฝน (ชม.แดดถ่วงน้ำหนักต่อวัน) • คะแนนสมดุล = แดดหน้าหนาว − ภาระความร้อน ยิ่งสูงยิ่งเหมาะกับห้องที่อยากเย็นหน้าร้อนและอุ่นหน้าหนาว • แถบสี ส้ม = ร้อน, เทา = ฝน/ช่วงกลาง, ฟ้า = หนาว • การแบ่งฤดูเป็นค่าประมาณตามปฏิทิน เปลี่ยนได้ที่ช่อง “ฤดูกาลของพื้นที่”

เทียบ 8 ทิศ ณ พิกัดนี้

ข้อมูลนี้คำนวณด้วย Python (NumPy) ตามสมการตำแหน่งดวงอาทิตย์ของ NOAA (Solar Position Calculator: Julian Day, Equation of Time, Declination, Hour Angle, Zenith, Azimuth) ทุก 5 นาทีตลอดปี ไม่รวมสิ่งบังแดด (ตึก ต้นไม้ ชายคา) เมฆ และการหักเหของบรรยากาศ ค่า “ความแรงของแดด” = cos(มุมสูง) × cos(ต่างมุมกับทิศผนัง) ซึ่งเป็นสัดส่วนแสงที่ตกฉากกับผนังแนวตั้ง
